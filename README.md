# My Old Projects

A personal archive of web development practice work, coursework, and mini-projects built while learning front-end development. Spans plain HTML/CSS/JS exercises through React, TypeScript, Tailwind, and Firebase experiments.

This is a raw archive, not a curated portfolio — expect duplicate/backup folders, inconsistent naming, and work-in-progress code.

## Contents

| Folder | What's inside |
|---|---|
| `programming_hero/` | Programming Hero bootcamp coursework — numbered assignments, HTML/CSS/Bootstrap exercises, JS practice, portfolio drafts |
| `project/` | Standalone JS mini-projects: password/quote/word/joke generators, QR code generator, stopwatch, to-do list, color scheme tool |
| `Portfolio/`, `Portfolio n/` | Personal portfolio site drafts |
| `Webite/` | Numbered website-building practice |
| `Responsive/` | Responsive layout and navbar practice |
| `others/` | Misc CSS design projects and Flexbox exercises |
| `test/` | Experimental builds (React + Vite) |
| `time_counter/` | Timer / countdown apps (React, Firebase) |
| `typescript/` | TypeScript practice — generics, unions, type reference |
| `rijwan er assignment/` | Assignment work shared with a classmate |
| `Lamia/`, `MAgic/` | Misc practice folders |
| `routine/`, `Tasks to do/` | Personal notes and task lists |
| `JS Custom Useful function/` | Reusable JS utility snippets |
| `w3 school js topics name scraping/` | Scraper script and scraped data for W3Schools JS topics |

## Tech

Vanilla HTML/CSS/JavaScript, TypeScript, React, Tailwind CSS, Firebase — mixed across projects depending on when each was built.

## Note on large files

A handful of large binaries (a video, a couple of `.rar`/`.zip` archives, a `.psd`) are intentionally excluded via `.gitignore` — they exceed GitHub's file size limit and aren't source code. They live only on the original machine.
